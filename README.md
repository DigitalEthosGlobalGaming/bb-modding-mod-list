# bb-modding mod list

A list of community mods for Bloodborne on a bbport build with
[bbmod](https://github.com/DigitalEthosGlobalGaming/bb-modding-v2). The bbmod mod
manager can be pointed at this repository (or any repository containing a
`modlist.json`) to add the listed mods, then download and enable them.

## modlist.json

See `modlist.schema.json`. Each entry gives the mod's `id`, `name`, git `repo`,
a `ref` (branch, tag or commit; prefer a tag or commit) and the minimum `abi`.

## Adding a mod

Open a pull request adding an entry to `modlist.json`.

**Listed mods are not vetted, audited or verified, and inclusion is not an
endorsement. Download and use them at your own risk.**
